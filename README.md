# CollegeMate AI
<br>
CollegeMate AI is an AI-powered assistant for diploma CSE students.
<br>
It provides college information, syllabus details and AI-based study help.
<br><br>
## Features
<br>
- College Information
<br>
- Syllabus Search
<br>
- AI Study Assistant
<br><br>

## Technologies Used
<br>
- Python
<br>
- Flask
<br>
- JSON
<br>
- OpenAI API
<br>
- Requests
<br><br>
## How to Run
<br>
<br>
1. Install required packages:
<br>
pip install flask requests python-dotenv openai
<br>
<br>
2. Create a `.env` file and add your OpenAI API key.
<br>
<br>3. Run:
<br>
python main.py
